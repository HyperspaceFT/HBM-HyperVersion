# Goal18B isolated verification

Part 1 covers the four sulfuric acid crystallizer groups appended to the production default table. These tools reuse the Goal18A recipe world (`goal18a_regression.common` helpers and `goal18a_regression.recipe_stubs`) without modifying it; only the output root, the fixture and the mutations are Goal18B's own. Run from the NEO repository with the existing Python 3 and JDK 21 (Windows PowerShell or Linux shell; classpaths use the platform separator):

- `python -B -X utf8 tools/migration/verify_goal18b_recipes.py`
- `python -B -X utf8 tools/migration/verify_goal18b_machine.py` (Linux: `python3 -I tools/migration/verify_goal18b_recipes.py`)

Outputs stay under unique directories in `build/migration/goal18b/recipes/`. The report records source, record, fixture, adapter, Gson and JDK hashes plus exact commands and exit codes; sources are hashed again after each command. A mutation counts only after successful compilation and an expected behavioral `AssertionError` (`sulfuric_groups_dropped`, `sulfuric_acid_replaced_by_peroxide`, `sulfuric_amount_halved`).

Production compiled: `CrystallizerRecipes` (36 default rows), `CrystallizerRecipeSync`, `CrystallizerRecipeClientSync`, `CrystallizerRecipesPacket`, `CrystallizerRecipeHandler`, the production loader base and `AssemblyMachineRecipes`; the frozen assembly baseline is `AssemblyMachineRecipes` from the Goal18A commit `ce94c2a`, read from git and compiled as `goal18b.base`. Stand-ins: the item/block registry (ids derived from field names; the verifier checks the eight ore and four crystal ids against the production registrations), tags, data components, SNBT, the byte-array packet buffer and the counting JEI runtime manager (`goal18a.JeiBridge`, bridged through the production `refreshCrystallizerRecipes` body). The real Gson jar is used.

Records read: `migration/goal18a-crystallizer-recipes.json` (the frozen Goal18A export) and `migration/goal18b-custom-crystallizer-merge-example.json` (how a player appends the four groups to an existing custom `hbmCrystallizer.json`, which still replaces the whole table). The run exports `goal18b-crystallizer-recipes.json` (minified default table) and reports `comparison` = added/removed/changed rows against the frozen Goal18A export, keyed on input identity plus acid type. No assembly rows are exported: Goal18B adds none and the fixture checks the table equals the baseline in both 528 modes.

`verify_goal18a_recipes.py` fails by design on the Goal18B tree at its `fourteen groups as 28 stone/deepslate rows` literal: Goal18A's evidence is its own historical report. The Goal18B verifier instead proves that the 28 Goal18A rows are unchanged and in place by comparing the production writer's first 28 rows with the frozen Goal18A export. Counts distinguish assertions, independent scenarios and executed production ticks (none here). Compilation and isolated services never prove game, config-directory, GUI, multiplayer or dedicated-server acceptance.

The machine world reuses the Goal18A machine world unchanged (`machine_stubs.py` is a pass-through) and compiles `Goal18BMachineRegression` over the Goal14C/18A fixtures. It drives the complete production `MachineCrystallizerBlockEntity` under sulfuric acid retyped through the identifier slot: the input filter and recipe follow the tank type, 499 mB never starts, 500 mB completes on the 601st sub-cycle with all acid consumed, a mid-process retype discards the acid and clears the progress, and NBT keeps the type and fill but not the progress. A finite tungsten chain (6 ore, 4,000 mB sulfuric acid from two statically priced `chem.sulfuricacid` batches, 1,700 mB kerosene in a real A0 turbofan, the production `PowerNetMK2` re-registered every tick feeding the crystallizer and the real centrifuge) yields 6 crystals in 3,606 ticks for 3,606,000 HE, then 24 tungsten powder, 6 iron powder and 6 tiny lithium powder in 1,200 centrifuge ticks for 240,000 HE, with 1,000 mB acid left and the energy identity checked every tick; 1,600 mB is shown to under-supply. A rare earth chain (601,000 HE from a 1,000 HE buffer plus a copper capacitor, then 40,000 HE in the centrifuge) yields 2 desh blend and 4 zirconium nuggets. A separate seeded Effectiveness-3 check replays the level random. Crystallizer and centrifuge rows are fixture-declared; the verifier resolves every production anchor they mirror, and those of the statically priced chemical plant, furnace and foundry tails, to file:line, fails if one is missing or ambiguous, and records them in `finite.json` and in `report.json` under `row_source_anchors`. Each mutation runs only its named scenario and must fail with the expected assertion.
